# Context

This project's ubiquitous language lives in [CONCEPTS.md](CONCEPTS.md). Read
that file for the shared vocabulary: entities, named processes, and statuses
with a meaning specific to The Rookery.

This pointer is a regular file rather than a symbolic link. The repository
forbids symbolic links, because Git on Windows checks one out as a text file
holding the target path, which would break Installation Parity.
