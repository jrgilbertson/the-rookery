# Security Policy

## Reporting a Vulnerability

If you find a security issue in anything this repo ships — a skill that mishandles untrusted input, a script with an unsafe default, instructions that could lead an agent to do something harmful — please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting: **Security tab → Report a vulnerability** on this repository.

You'll get an acknowledgment as soon as I've seen it. This is a solo-maintained project, so there's no formal response-time guarantee — but security reports go to the front of the line.
