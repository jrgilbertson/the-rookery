# Security Policy

## Reporting a Vulnerability

If you find a security issue in anything this repo ships, please report it privately rather than opening a public issue. That covers skills that mishandle untrusted input, scripts with unsafe defaults, and instructions that could lead an agent to do something harmful.

Use GitHub's private vulnerability reporting under the **Security** tab on this repository.

You'll get an acknowledgment as soon as I've seen it. This is a solo-maintained project, so there is no formal response-time guarantee, but security reports go to the front of the line.
