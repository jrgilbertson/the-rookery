# The workflows

The [README](README.md) names seven jobs. This file holds the walkthroughs.

Sections marked as arriving are honest placeholders, not forgotten drafts. Each walkthrough gets written from the real workflow as it runs today, not an idealized version of it.

## Research

**The job.** Gather real signal before deciding anything. Know what people are actually using, what changed this month, and what the strongest competing approaches look like.

**The tools.** [last30days](https://github.com/mvanhorn/last30days-skill) for recent signal across Reddit, X, YouTube, HN, and the web. Multi-perspective deep research for questions where blind spots are expensive.

**Status.** Walkthrough arriving.

## Plan

**The job.** Turn intent into work worth doing. Generate grounded ideas, pressure-test scope before committing, and produce plans an agent can execute without inventing decisions.

**The tools.** [Compound Engineering](https://github.com/EveryInc/compound-engineering-plugin) end to end. Ideate for grounded options, brainstorm for requirements, plan for the implementation contract.

**Status.** Walkthrough arriving.

## Design

**The job.** Interfaces that hold up under real use. Visual hierarchy, accessibility, motion, and polish treated as engineering concerns rather than afterthoughts.

**The tools.** [Impeccable](https://github.com/pbakaus/impeccable) as the design driver for every frontend surface.

**Status.** Walkthrough arriving.

## Build

**The job.** Implement with a fleet, not a single thread. Parallel worktrees, delegated tasks, and terminal orchestration, with each agent owning a bounded slice.

**The tools.** [Orca](https://github.com/stablyai/orca) as the agentic IDE. Compound engineering's work loop for executing plans.

**Status.** Walkthrough arriving.

## Ship

**The job.** Land it clean. Review gates run before the PR does, changelogs and release notes write themselves from what actually shipped.

**The tools.** Compound engineering's review flow, plus skills for pre-PR approval and changelog writing that arrive here with the first flock.

**Status.** Walkthrough arriving.

## Maintain

**The job.** Keep repos and systems healthy over time. Bounded hygiene passes, architecture reviews, eval design, and data quality checks that catch drift before users do.

**The tools.** Skills for repo maintenance, repo best practices, architecture review, eval design, and data validation. They arrive here with the first flock.

**Status.** Walkthrough arriving.

## Learn

**The job.** Turn what you read and build into durable knowledge instead of vibes. Atomic notes, connected thinking, and learnings that compound back into the system that produced them.

**The tools.** Networked Thinking for the note system and the thinking behind it. More learning skills are in testing and land here once they earn their place.

**Status.** Walkthrough arriving.
