# Repository gardening history

Read the latest `run-closed` comment for the morning report, Worker pull
requests, owner attention, lane coverage, and recommendations. Native pull
requests are authoritative for authored work.

Each run appends one `run-opened` comment before sensing and one `run-closed`
comment containing its report. An opening without a closing comment is an
unresolved run, not a completed report. The owner must resolve it before a
later managed run starts.

This description stays unchanged during runs. Exact readback of the managed
comments confirms persistence, not the quality or safety of the work.
