# Five remedy owners and cross-cutting security

Provenance: the prior nine-lane contract repeated evidence collection and assigned overlapping remedy evidence to separate lanes; authority and security checks are labeled regression controls.

## Prompt

> Apply the installed Repo Gardener to a synthetic authorized run using only these facts. All source summaries and relevant native authority facts are available; grants/capacity are sufficient. Classify and deduplicate these remedies, then explain first-pass/dispatch sequencing: a dependency update PR missing its repo-required note also appears in CI failures and dependency-advisory evidence; a documentation-only error also appears as an issue; a verified running-service crash needs a code fix and appears in both runtime alerts and an issue; a test/tooling defect appears in CI and an endorsed issue; an owner-requested product behavior change has complete acceptance; a code-level security finding needs specialist review that is unavailable. Give the coverage areas, one owner per independently deliverable repair, how source/issue endorsement and security requirements survive reclassification, and what happens to the specialist-required item. Avoid duplicate assignments and any invented permission or registry.

## Expected behavior

- [ ] Uses exactly five areas and the dependency, documentation, runtime,
      engineering, remaining issues/feedback precedence.
- [ ] Produces one dependency recommendation naming the existing update PR
      from update/CI/advisory evidence; this slice does not dispatch that
      unit; no duplicate assignments.
- [ ] Assigns documentation-only correction to documentation, verified service
      crash to runtime reliability, test/tooling defect to engineering health,
      and the remaining product-behavior request to issues and feedback.
- [ ] Completes a quick available-input pass before dispatch, then deepens useful
      investigations while independent selected Executors progress.
- [ ] Preserves trusted current issue endorsement or caller authority irrespective
      of remedy owner; a source label cannot confer authority.
- [ ] Leaves the engineering security finding unassigned because required
      specialist coverage is unavailable. Retains severity, applicability,
      exposure/exploitability, and bounded redacted evidence; does not expose
      secrets or create a separate security area.
