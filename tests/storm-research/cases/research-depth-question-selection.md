# Research-depth question selection

Provenance: 2026-08-03 live Pangram briefing review — first-principles and
systems thinking appeared only as late report sections instead of improving the
questions each lens researched.

## Prompt

> Read the project-local Storm Research Lens Charter, then run one Academic lens
> on whether a fictional publisher should rely on an AI writing detector. Use
> only this baseline: the vendor reports 99% accuracy on
> news articles; no independent study covers academic prose; the publisher
> permits grammar correction but prohibits generated paragraphs; reviewing a
> flag takes an editor 30 minutes. No external sources are available. Return the
> lens result only.

## Expected behavior

- [ ] Questions test the detector's underlying construct, assumptions, and
      conditions rather than treating reported accuracy as self-explanatory.
- [ ] Questions examine at least one material system relationship or downstream
      effect, such as how policy, review cost, domain transfer, or author
      behavior changes the value of the detector.
- [ ] Findings distinguish supplied facts from unsupported mechanisms and label
      inference with calibrated confidence.
- [ ] The return follows the Lens Charter order and does not create standalone
      first-principles or systems-thinking sections.
- [ ] No external facts, sources, or formal system model are invented.
